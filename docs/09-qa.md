# 09 — QA

No CI service is part of this project, but `npm run validate` is what a CI job would run. Everything below runs locally.

## Content validation (`tests/content.test.ts`)

For every topic in the catalog:

1. The topic module loads and its `course`/`slug` match the catalog entry.
2. `count` equals `challenges.length`.
3. Every challenge passes a schema guard: required fields present, `difficulty` in 1..3, `kind` valid, at least 2 tests, slug is kebab-case and unique within the topic, title non-empty, description contains an example (a backtick code span containing `→` or a fenced block).
4. `solution` passes every test (run through the real harness in `happy-dom`, with `html` applied).
5. `starter` fails at least one test, or throws, or has a syntax error.
6. `predict` challenges: the solution's `expected` array equals the captured logs, and the starter's empty `expected` does not.
7. Total across all topics equals 353 (a constant in the test, updated deliberately when content is added).
8. The generated `difficulties` array in the catalog matches the topic file.

Runs in under 30 seconds. Each topic is a `describe` so `-t "practice/dates"` runs one.

## Unit tests

- `harness.test.ts`: script building, error line mapping, assertion library.
- `progress.test.ts`: store mutations, streak calculation, import merge rules, corrupt storage recovery.
- `nextChallenge.test.ts`: all fallthrough cases.
- `interview.test.ts`: picker.

## Static checks

- `tsc --noEmit` with `strict`, `noUncheckedIndexedAccess`, `noUnusedLocals`.
- ESLint with the Vite React defaults plus `react-hooks`.
- Prettier check.

## Manual smoke checklist (before calling the project done)

1. Fresh clone, `npm install`, `npm run dev`, open the dashboard. No console errors.
2. Open each course page and one topic per course.
3. Solve one challenge of each kind: implement, fix, complete, predict, DOM.
4. Trigger each failure mode: syntax error, runtime error, failing assertion, infinite loop (`while (true) {}`), unhandled rejection.
5. Reload mid-challenge: draft restored. Reset: starter restored.
6. Export progress, reset, import, confirm the dashboard matches.
7. Run an interview session to completion and one that times out.
8. Resize to 800px wide: sidebar collapses, workbench still usable.
9. `npm run build && npm run preview`: the built app behaves the same, and the sandbox iframe loads from `/sandbox.html`.
10. Keyboard-only pass through a challenge: Tab to editor, type, Cmd/Ctrl+Enter, Tab to Next, Enter.
