# brush-up-on-javascript — project plan

A JSChallenger-style practice site for developers with years of experience who want to refresh JavaScript or prepare for technical interviews. Challenges only. No lessons, no accounts, no paywall, no deployment. Clone it, `npm install`, `npm run dev`.
